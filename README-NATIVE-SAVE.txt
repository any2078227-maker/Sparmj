LifeOS Android export fix

Export Word, Excel and Backup now use a native Android save bridge inside the Capacitor APK.
The Android app opens the system Save dialog and writes the generated bytes to the location selected by the user.
Browser fallback remains the normal download behavior.

Important: Word/Excel exports remain HTML-based .doc/.xls files, as in the original app. This change fixes Android file saving; it does not convert them into true OOXML .docx/.xlsx files.
